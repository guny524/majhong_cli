# Riichi Mahjong Terminology Reference

**Purpose**: Comprehensive glossary of Mahjong terminology in multiple languages for implementation consistency.
**Referenced by**: All constitution documents
**Last Updated**: 2025-11-18

## Notation Convention

**Format**: English / Korean / Japanese / Chinese

All terms throughout constitution documents follow this four-language notation to prevent confusion.

### Hand States

| English | Korean | Japanese | Chinese | Definition |
|---------|--------|----------|---------|------------|
| Closed hand | 멘젠 | 門前 (Menten/Menzen) | 門清 (ménqīng) | No called melds (chi/pon/open kan), only concealed tiles |

## Usage Guidelines for Implementation

### Code Naming Conventions

**Use English terms for code identifiers**:
```python
class Hand:
    def __init__(self):
        self.closed_tiles = []  # Use "closed" not "menzen"
        self.called_melds = []  # Use "called" not "furo"
        self.is_riichi = False
        self.is_tenpai = False
```

**Use Japanese romanization for yaku enum values**:
```python
class Yaku(Enum):
    RIICHI = "riichi"
    PINFU = "pinfu"
    TANYAO = "tanyao"
    YAKUHAI = "yakuhai"
    HONITSU = "honitsu"
    CHINITSU = "chinitsu"
```

### Documentation and UI

**Use four-language notation in documentation**:
```markdown
## Closed Hand / 멘젠 / 門前 (Menten) / 門清 (ménqīng)

A closed hand (menzen) contains no called melds...
```

**Use localized terms in user-facing UI** based on user language preference:
- English players: "Closed hand"
- Korean players: "멘젠"
- Japanese players: "門前"
- Chinese players: "門清"

### Comments in Code

**Include terminology references**:
```python
def check_menzen(hand):
    """
    Check if hand is closed (no called melds).

    Menzen / 멘젠 / 門前 / 門清: Closed hand with no chi/pon/open kan.
    Required for many yaku like riichi, pinfu, iipeikou, etc.
    See constitution_term.md: Hand States
    """
    return len(hand.called_melds) == 0
```

## Common Confusion Points

### Menzen vs. Closed Wait

- **Menzen (門前)**: Hand state - no called melds
- **Closed wait (嵌張)**: Wait type - waiting on middle of sequence

### Furiten vs. Not Tenpai

- **Furiten (振聴)**: CAN win (tenpai) but CANNOT ron (self-discard or temporary)
- **Noten (不聴)**: CANNOT win at all (not one away)

### Dora vs. Yaku

- **Dora**: Bonus tile adds han but IS NOT yaku
- **Yaku**: Scoring pattern, MUST have at least 1 to win
- Dora alone cannot enable winning

### Kan Types

- **Daiminkan (大明槓)**: Open kan from discard → hand becomes open
- **Shouminkan (小明槓)**: Add to existing pon → hand remains open
- **Ankan (暗槓)**: Concealed quad from hand → hand stays closed

### Wait Type Names

- **Ryanmen (両面)**: Good wait, most flexible (waits 3 or 6 from 4-5)
- **Kanchan (嵌張)**: Middle wait, less flexible (waits 5 from 4-6)
- **Penchan (辺張)**: Edge wait, restricted (waits 3 from 1-2, or 7 from 8-9)
